# Small input templates

comparisons.csv demonstrates the comparison-manifest format. Replace paths/conditions with
independent runs with matched procedures and observation durations. They are placeholders, not
claims that those runs already exist. Use report/summary.json, not the top-level session summary.

events_template.csv demonstrates reviewed explicit events. Generate new trace CSVs with oaiho trace; they are not measured channels or RF authorization.
a3_grid.yaml is a future scheduler input, not a qualified A3 run configuration.
